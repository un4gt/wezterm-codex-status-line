# Contributing

The source code is on [GitHub](https://github.com/un4gt/wezterm-codex-status-line).

See the [contributing guide](https://github.com/un4gt/wezterm-codex-status-line/blob/main/CONTRIBUTING.md) for build, test, and local documentation-site instructions.

For usage problems, start with [Troubleshooting](../troubleshooting/common-issues.md). When opening an [Issue](https://github.com/un4gt/wezterm-codex-status-line/issues), include your OS, WezTerm, Codex, and plugin versions and clear reproduction steps.
