首次通过 PyPI 发布，可直接使用 uvx 安装。

### 更新

- 启用终端标题桥后，`/model` 切换会立即同步模型名，无需发送新消息。
- 升级旧标题桥时自动补上模型字段，并保留卸载所需的原始配置。
- 累计费用按各次请求实际使用的模型计算，切换模型不会重算既有用量。
- 仅版本标签触发 PyPI 发布；npm 安装包继续作为 GitHub Release 附件提供。

### 安装

```sh
uvx wezterm-codex-status-line@0.1.1 install --no-title-bridge
```

Windows 用户需要实时同步模型时，将 `--no-title-bridge` 换成 `--title-bridge`。安装后重新加载 WezTerm 配置，再启动或恢复 Codex 会话。

使用 npx：

```sh
npx --yes --package=https://github.com/un4gt/wezterm-codex-status-line/releases/download/v0.1.1/wezterm-codex-status-line-0.1.1.tgz wezterm-codex-status-line install --no-title-bridge
```

更新已有安装：

```sh
uvx --refresh wezterm-codex-status-line update
```

macOS 暂未完成实机验证，Linux 暂未完成 Wayland/X11 桌面验证；这两个平台请保留 `--no-title-bridge`。
