为 WezTerm 中的 Codex CLI 添加底部状态栏，显示模型、推理强度、工作目录、Git 分支和 Token 用量。

### 功能

- 每个 Codex 窗格显示独立的会话信息。
- 配置字段顺序、颜色、图标和一行或两行布局。
- 显示输入、输出、缓存率和估算费用。
- 在网页中预览配置并导出 JSON。

### 安装

使用 npx：

```sh
npx --yes --package=https://github.com/un4gt/wezterm-codex-status-line/releases/download/v0.1.0/wezterm-codex-status-line-0.1.0.tgz wezterm-codex-status-line install --no-title-bridge
```

或使用 uv：

```sh
uvx --from https://github.com/un4gt/wezterm-codex-status-line/releases/download/v0.1.0/wezterm_codex_status_line-0.1.0-py3-none-any.whl wezterm-codex-status-line install --no-title-bridge
```

安装后，在 WezTerm 配置中加入 `require("codex_statusline").setup()`，重新加载配置，再启动 Codex。

### 配置

打开[交互预览](https://un4gt.github.io/wezterm-codex-status-line/preview/)，调整显示内容并下载 JSON。使用 `configure --from <文件路径>` 导入后，重新加载 WezTerm 配置。完整命令见[配置指南](https://un4gt.github.io/wezterm-codex-status-line/docs/guides/configuration/)。

### 平台说明

macOS 暂未完成实机验证；Linux 暂未完成 Wayland/X11 桌面验证。这两个平台安装时请保留 `--no-title-bridge`。

### 更新与卸载

使用 `update` 更新，使用 `uninstall` 卸载。卸载前先从 WezTerm 配置中移除模块引用并重新加载配置。步骤见[更新与卸载](https://un4gt.github.io/wezterm-codex-status-line/docs/getting-started/update-uninstall/)。
