这是首个小范围测试版本，通过 GitHub Release 附件分发，无需 npm/PyPI 账号或密钥。npm 和 PyPI 尚未发布本项目包。

选择以下一种方式安装。`npx` 从远程 tarball 安装并运行包内 CLI；`uvx` 从远程 wheel 创建临时环境并运行相同的命令入口。

### 使用 npx

```sh
npx --yes --package=https://github.com/un4gt/wezterm-codex-status-line/releases/download/v0.1.0/wezterm-codex-status-line-0.1.0.tgz wezterm-codex-status-line install --no-title-bridge
```

### 使用 uvx

```sh
uvx --from https://github.com/un4gt/wezterm-codex-status-line/releases/download/v0.1.0/wezterm_codex_status_line-0.1.0-py3-none-any.whl wezterm-codex-status-line install --no-title-bridge
```

安装后，在 WezTerm 配置中加入 `require("codex_statusline").setup()`。需要配置、预览或检查时，保留命令中的远程包地址，将末尾的 `install --no-title-bridge` 换为 `configure`、`preview` 或 `doctor`。更新使用 `update --no-title-bridge`。

### 测试范围与已知问题

- Windows 已通过 bridge/CLI 测试，以及真实 WezTerm 的 50 次局部分屏创建与回收验证。
- macOS 因缺乏设备，尚未进行实机测试；Linux 尚未进行 Wayland/X11 真实 GUI 验证。
- 非 Windows 的 title bridge 存在 RPC 初始化问题，本次安装使用 `--no-title-bridge`。
- 卸载前请先从 WezTerm 配置中移除所有对 `codex_statusline` 的引用并重新加载配置，再执行 `uninstall`。当前保护检测不能识别所有合法 Lua 写法。

包内包含固定版本的全部 Lua 模块、bridge、配置 contract 和 MIT LICENSE。源码包也随本版本提供。
