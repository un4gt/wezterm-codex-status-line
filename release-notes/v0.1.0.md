在 WezTerm 中为 Codex CLI 显示独立的底部状态栏，包含模型、reasoning effort、工作目录、Git 分支和 token/context 用量。支持网页交互预览、JSON 配置，以及 `npx` 和 `uvx` 安装入口。

选择以下一种方式安装 v0.1.0。两个入口提供相同的安装、配置、更新和卸载功能。

### 使用 npx

```sh
npx --yes --package=https://github.com/un4gt/wezterm-codex-status-line/releases/download/v0.1.0/wezterm-codex-status-line-0.1.0.tgz wezterm-codex-status-line install --no-title-bridge
```

### 使用 uvx

```sh
uvx --from https://github.com/un4gt/wezterm-codex-status-line/releases/download/v0.1.0/wezterm_codex_status_line-0.1.0-py3-none-any.whl wezterm-codex-status-line install --no-title-bridge
```

安装后，在 WezTerm 配置中加入 `require("codex_statusline").setup()`。需要配置、预览或检查时，保留命令中的远程包地址，将末尾的 `install --no-title-bridge` 换为 `configure`、`preview` 或 `doctor`。更新使用 `update --no-title-bridge`。

### 配置状态栏

在[交互预览](https://un4gt.github.io/wezterm-codex-status-line/preview/)中调整显示内容并下载 JSON，然后使用 `configure --from <文件路径>` 导入。导入后重新加载 WezTerm 配置。完整步骤见[配置指南](https://un4gt.github.io/wezterm-codex-status-line/docs/guides/configuration/)。

### 兼容性与卸载

- macOS 暂未完成实机验证；Linux 暂未完成 Wayland/X11 桌面验证。
- macOS 和 Linux 安装时请保留 `--no-title-bridge`，这两个平台暂不支持自动配置 Codex terminal title。
- 卸载前，从 WezTerm 配置中移除对 `codex_statusline` 的引用并重新加载配置，再执行 `uninstall`。
